# HAQ V2 - Synthetic QA data pack (2026-10-11)

**كل البيانات خيالية بالكامل، ومصممة للاختبار فقط.** ليست عقودًا نافذة أو مصادر قانونية رسمية، ولا تتضمن هويات وطنية أو وسائل تواصل حقيقية.

## المحتويات

- `enterprise_contracts/`: **36 عقدًا خياليًا** لثلاث شركات مختلفة، بصيغة PDF نصية قابلة لاختبار extraction.
- `citizen_test_contracts/`: **6 ملفات PDF** للفحص الفردي، منها مستند غير قانوني لاختبار الرفض.
- `ocr_scans/`: **6 ملفات** بينها صور بجودات مختلفة، PDF صورة فقط، وصورة فارغة لاختبار بوابة الرفض.
- `data/enterprise_portfolios.json`: علاقات الشركة والعقود والموضوعات المراد اختبارها.
- `data/enterprise_index.csv`: فهرس قابل للفرز.
- `data/citizen_test_cases.json`, `ocr_test_cases.json`: السيناريوهات المتوقعة لاختبارات التحميل والـOCR.
- `data/demo_lawyer_prices.json`: **8 ملفات محامين خيالية للعرض المحلي فقط**؛ ليست محامين مرخّصين ولا تقييمات حقيقية. الأسعار أرقام توضيحية لا تمثل أسعار السوق.
- `impact_scenarios/`: محاكاة تعديل تشريعي خيالي، بلا ادعاء مصدر رسمي أو مخالفة مثبتة.

## كيف نستخدمها

1. شغّل HAQ في بيئة **demo/mocks محلية معزولة** لا تتصل بمشروع Supabase Production.
2. اعرض الشركات والعقود والأسعار التجريبية في الـDemo فقط وبشارة واحدة مفهومة.
3. افحص العقود PDF والصور يدويًا ضمن سير التحليل بعد تجهيز قاعدة بيانات اختبار مناسبة.
4. استعمل `expected_topic_flags` لمقارنة **اكتشاف الموضوعات** وليس للحكم على شرعية البنود؛ لا تستبدل المراجعة القانونية.
5. لا ترفع ملفات المحامين الخياليين إلى Marketplace الحقيقي أو توصفهم بأنهم موثقون.
6. لا تُظهر أن التعديل التشريعي الافتراضي قانون نافذ. أثر التعديل = حاجة محتملة لإعادة المراجعة فقط.

## سلامة الإنتاج

قاعدة HAQ الحالية موسومة `PRODUCTION`، ودالة `request_case_once` كانت مفقودة. هذه الحزمة **لا تتضمن سكربتات INSERT أو تشغيل عن بُعد**. لا تستوردها لقاعدة الإنتاج دون نسخ احتياطية صالحة وخطة عزل وعودة واضحة وموافقة تنفيذ منفصلة.

## تفاصيل الأسعار

أضف للمحامي الموثق حق تعديل سعر الاستشارة من ملفه الشخصي (وحين تدعمها البنية: سعر مراجعة المستند والمدة). المصدر الصحيح للقيمة هو سجل المحامي المصرح له، وليس بيانات المتصفح. سعر صفر يعرض مجاني فقط لو اختار المحامي ذلك صراحة؛ بخلاف ذلك يعرض `السعر عند التواصل` بدل `0 دينار`. اشتراك المحامي مع HAQ شيء منفصل تمامًا عن أتعاب استشارته مع المواطن.
